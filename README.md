## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/abinayakumar-06/javaprograms.git
```

### 2. Open the project

Open the repository in your preferred Java IDE or code editor.

### 3. Compile the program

```bash
javac ProgramName.java
```

### 4. Run the program

```bash
java ProgramName
```
